神経衰弱 — 遊び方

裏向きに並んだ札から2枚をめくります。

そろった：2枚が同じ数字（スートは問わない）なら、その2枚をもらって続けて自分の番。
外れ：違う数字なら少し見せてから裏に戻し、次の人の番。どこに何があったかを覚えておくのがコツ。
終了：札が全部なくなったら終わり。取った組数が多い人の勝ち。同数なら引き分け。ひとりのときは手数とタイムを競い、自己ベストをこの端末に記録します。
枚数：24枚＝A〜Qのスペードとハート（12組）／36枚＝A〜9の4スート（18組）／52枚＝全部（26組）。
CPU：見た札の場所を覚えますが、強さに応じて忘れます（やさしい 50%／ふつう 25%／つよい 5%）。覚えている組があれば取りにいき、無ければまだ見ていない札をめくります。

オンライン対戦：ホストが部屋を作り、相手は4桁コードか招待URLで参加（最大4人・CPU補充可）。途中で退出した席はCPUが代わりにめくります。60秒反応が無い人は「離脱中」と表示されます。
