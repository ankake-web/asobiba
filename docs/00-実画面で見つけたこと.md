2026-08-15 / スクショは `shots/` に43枚。コード監査（→ `01-優先度レポート.md`）とは別に、
**実際にブラウザで動かして目で見た**結果だけをここにまとめる。コード読みでは出てこない不具合が中心。

計測系の結果（全ページ共通）:
- 横スクロールの発生: **全ページで無し**（scrollWidth == clientWidth）。ここは合格。
- 起動時のJSエラー: あそびばの App Check 警告（localhost では正常）以外は無し。

## A. 一番効くのは「あそびばのハブ」— 巨大絵文字が主役になっている

`shots/hub-full.png`

5枚のゲームタイルすべてで、**カード右下の120〜160pxの絵文字が事実上の主役ビジュアル**になっている。
しかも OS 標準絵文字のフラットな絵柄なので、せっかくのグラデーション背景から完全に浮いていて、
半分見切れた状態で置かれている。うまうまレースには実写級のCG馬（`games/uma-race/assets/horse-*.jpg`）が
既にあるのに、ハブでは使われていない。

同じ画面でもう1つ:
- タイル5枚のグラデが**バラバラ**（緑→黄→ピンク / 青 / 深緑 / 青 / 紫）。特に1枚目の緑→黄が浮く。
- ヒーロー内に🎲🏇が薄く配置され、意味不明な影に見える。
- フッターの「🧡」も絵文字。

→ ここを直すのが投資対効果が最も高い。全ゲームの入口なので。

## C. うまうまレースの「ロビー以降」がリスキン前のまま取り残されている

`shots/uma-race-phone.png`（トップ）と `shots/uma-race-lobby.png`（部屋を作った後）を並べて見ると別ゲーム。

- **トップ**: 夕暮れのターフの実写級CG＋ダークな枠。かっこいい。
- **ロビー**: ヒーロー画像が**読み込めておらず**、緑の縞グラデ＋🏇絵文字の巨大な影になっている。
  背景もクリーム色の白基調で、トップの世界観がどこにも残っていない。

これは監査の「うまうまレースが最低スコア（2.5）」の理由をよく説明している。

## D. カタンの「🀄 コマ・カード図鑑」が豆腐（□）で文字化けしている

`shots/catan-full.png`

Windows / Chromium 環境で麻雀牌の絵文字がフォント未対応で **□ の四角**として描画されている。
百万石側（📜）は化けていない。絵文字を使うと、こういう「端末によっては□になる」事故が起きる。
絵文字をやめる理由の実例として一番わかりやすい。

## L. 逆に「思ったより良い」もの

ユーザー本人が「手を加えられていない」と感じているヘルパゴスは、**実際にはかなり出来が良い**。

- カード絵・背景・結果画面のアートが水彩調で統一されていて、11本の中でも上位（`shots/9-late.png` の「全滅」画面）。
- ヘッダーが **☰ メニュー1個に集約**されている（好みに合致）。
- 「木集め」の追加引き本数を**スライダー**で選ばせている＝数字だけでなく操作で押し引きを表現（`shots/6-action.png`）。
- アイコンがSVGで、絵文字が画面上にほぼ出ない。

ドミニオンも同様で、カードアートと金×深紫の配色は市販アプリに近い品位がある（`shots/dominion-game.png`）。
この2本は「作り直し」ではなく「詰め」のフェーズ。
